PÁGINA DE VENDAS
------------------------------------------------------------

index.html

Todos os principais botões da página direcionam para
o checkout da Kiwify.


RASTREAMENTO
------------------------------------------------------------

Os botões utilizam parâmetros UTM para identificar
diferentes origens de acesso.

Exemplos:

utm_source=site
utm_medium=hero
utm_medium=offer
utm_medium=final_cta
utm_medium=floating

Esses parâmetros podem ser utilizados para organizar
as campanhas e identificar a origem dos acessos.


PÁGINA DE OBRIGADO
------------------------------------------------------------

obrigado.html

Esta página foi criada para servir como experiência
personalizada após a compra.

Para utilizar uma página externa de obrigado na Kiwify,
configure o endereço da página publicada na Vercel
dentro das configurações correspondentes do produto.


PUBLICAÇÃO
------------------------------------------------------------

O projeto pode ser publicado na Vercel.

Não é necessário servidor próprio.

Basta conectar o repositório GitHub à Vercel ou fazer
o deploy diretamente pela plataforma.
